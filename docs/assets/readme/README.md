# README 插画

这套图用于仓库和四个插件首页：纸感底色、石墨线条、少量蓝橙点缀。每张图表达一个工具的用途，正文负责讲清安装和操作。

![四个插件的插画总览](cover.png)

## 文件与用法

| 文件 | 用途 | 图中表达的内容 |
| --- | --- | --- |
| `cover.png` | 仓库首页 | 任务、接口、代码、数据库四种工具 |
| `task-panel-cover.png` | 任务看板 | 排任务，并关联处理任务的会话 |
| `api-client-cover.png` | API 调试台 | 请求、响应和变量 |
| `local-review-cover.png` | 本地代码审查 | 比较改动，在代码行上留批注 |
| `dbx-cover.png` | DBX | 本地容器中的查询与结果 |

图片是用内置 `imagegen` 生成的原创概念插画。插件封面以总封面的材质、线条和配色为参考，分别生成独立构图；图中没有真实界面、业务数据或私人路径。完整提示词见 [prompts.md](prompts.md)。

## 维护这套图

- 封面保持约 3:1 的横幅比例，标题和安装命令写在 Markdown 正文里。
- 不把界面截图、假界面或大段文字混入封面。
- 改图时保留一致的纸感、线条与蓝橙配色；新增主题先讲清用途，再安排画面。
- 所有被 README 引用的图片都放进仓库，使用相对路径。
