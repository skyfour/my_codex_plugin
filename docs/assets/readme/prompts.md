# README 插画提示词

使用内置 imagegen 生成。四个插件封面仅参考总封面的线稿、纸张和配色，分别生成独立构图。

## cover

Use case: illustration-story. Asset type: original illustrated cover banner for the README of a personal collection of four Codex developer plugins. Create one panoramic illustration, aspect ratio 3:1, approximately 1536 by 512. Subject: four distinct developer tools arranged along one calm horizontal workbench: a compact row of movable task cards; a pair of plugs with a clean request-and-return path; two pages of source code with a margin annotation; and a small stacked database cylinder beside a query strip. Treat these as expressive, symbolic illustrated objects, never a screen or a screenshot. Style: restrained editorial technical illustration, careful graphite-black outlines, warm white paper, sparse burnt-orange and muted blue accents, small solid ink shapes, generous breathing room, coherent scale, subtle print character. Quiet, useful, a little handmade; suitable for a small open source utility maintained by one person. No text, no letters, no words, no watermarks or logos. No browser chrome, realistic app UI, mockup, dashboard, gradients, glow, neon, 3D, robots, or stock business imagery. All four objects are fully within the image with generous margins.
